# אריזה והתקנה כאפליקציית אנדרואיד

האפליקציה נארזת כאפליקציית אנדרואיד אמיתית (Capacitor) על ידי GitHub, בלי להתקין שום דבר על המחשב.
התוצאה היא קובץ APK שמתקינים על הטלפון.

## הגדרה חד-פעמית: שני סודות ב-GitHub

מעבר ל-6 הסודות של Firebase שכבר קיימים, יש להוסיף שניים (שמות בדיוק כך):

| שם הסוד | מה הערך |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | מפתח החתימה של האפליקציה, כטקסט אחד ארוך (נמסר בנפרד בצ'אט) |
| `ANDROID_KEYSTORE_PASSWORD` | הסיסמה של המפתח (נמסרה בנפרד בצ'אט) |

הוספה: https://github.com/shuey0504134506-web/family-finance/settings/secrets/actions ← **New repository secret**.

**חשוב:** המפתח הוא ה"חותמת" של האפליקציה. עדכון של אפליקציה מותקנת אפשרי רק עם אותו מפתח.
יש לשמור עותק שלו (והסיסמה) במקום בטוח ופרטי. אם יאבד, אפשר ליצור מפתח חדש, אבל אז צריך להסיר את
האפליקציה מהטלפון ולהתקין מחדש (הנתונים עצמם נשמרים ב-Firebase ולא הולכים לאיבוד).
אין לשמור את המפתח בתוך הקוד או לשלוח אותו לאחרים.

## בניית הקובץ

1. https://github.com/shuey0504134506-web/family-finance/actions
2. **בניית אפליקציית אנדרואיד (APK)** ← **Run workflow** ← **Run workflow**.
3. אחרי כ-10 עד 15 דקות מופיע וי ירוק. הקובץ נמצא ב-**Releases**:
   https://github.com/shuey0504134506-web/family-finance/releases

אם יש X אדום: ללחוץ עליו, לפתוח את השלב שנכשל ולשלוח לי את ההודעה.

## התקנה בטלפון

1. בטלפון פותחים את כתובת ה-Releases (למעלה) ב-Chrome, ובגרסה האחרונה מורידים את הקובץ `family-finance-….apk`.
2. פותחים את הקובץ שהורד. אנדרואיד ישאל אם לאפשר התקנה מהדפדפן: מאשרים (Settings ← "Allow from this source").
3. אם מופיעה אזהרת Play Protect "אפליקציה לא מוכרת": **More details ← Install anyway**. זה צפוי, כי האפליקציה לא הועלתה ל-Google Play.
4. נכנסים עם אותו מייל וסיסמה כמו באתר. הנתונים זהים.

## עדכון גרסה

מריצים שוב את ה-workflow. כל הרצה מוסיפה Release חדש עם מספר גרסה גבוה יותר. מתקינים אותו מעל הקודם, וללא מחיקה.

## מה מובן מאליו וחשוב לדעת

- שם החבילה הוא `com.familyfinance.app`. אם בעתיד תעלה ל-Google Play, השם קבוע ולא ניתן לשינוי אחרי העלאה, ולכן צריך להחליט עליו לפני כן.
- ה-Releases של Repository ציבורי גלויים לכולם. ה-APK אינו מכיל סיסמאות או נתונים אישיים, אבל כל אחד יכול להוריד אותו. הנתונים עצמם מוגנים בהתחברות ובחוקי האבטחה.
- האפליקציה הארוזה מציגה את אותה גרסת אתר שנבנתה בעת הבנייה. כדי לקבל שינויים בקוד, יש לבנות APK חדש (האתר ב-GitHub Pages מתעדכן לבד).
- כפתור Back: במסך פנימי חוזר צעד אחורה, ובמסך הראשי יוצא מהאפליקציה בלי להתנתק ובלי למחוק מידע.
- גיבוי אנדרואיד האוטומטי כבוי בכוונה, כדי שנתונים פיננסיים לא יועתקו לענן של Google מחוץ ל-Firebase.
