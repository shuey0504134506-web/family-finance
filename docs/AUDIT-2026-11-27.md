# Family Finance — code and security audit, 27 November 2026

Baseline: `22387cb5657741f30edb03da53e329876eec9f10` (main). Scope: shared web and mobile code, Windows local storage and sync, Firebase backend and rules, financial parsing, AI summaries, update integrity, CI and npm dependencies. All test data were fictitious. No production records, credentials, billing settings or deployed rules were changed.

## Verified corrections

- Preserve newer local edits while an older write is synchronizing, even when the operation type is unchanged. Stop subsequent sync operations on logout and isolate callbacks from a stopped session. Preserve existing local vaults when the cloud password differs instead of deleting them. Validate the identity returned by cloud sign-in and wait for connected-session initialization before callable requests.
- Re-key the authenticated React subtree and transaction listeners by user identity; do not return stale disabled-scope transaction lists.
- Reject malformed thousands separators, ambiguous decimals, duplicate signs and unsafe numeric values in manual entry and bank statement import.
- Carry the real primary currency into the AI summary and fallback, label debts and standing instructions in their original currencies, disclose transactions excluded because exchange rates are missing, and use the requested previous month in local summaries. Clean delimiters from compact data fields; block requests when relevant data sources report errors.
- Windows updater: require a published, strictly newer version; verify exact asset name, length and SHA-256 against official GitHub release metadata in the main process before opening the installer. Bound download time and size, use a unique temporary directory and clean failed downloads. No claim of publisher code-signing is made.
- Remove the unreferenced percentage module, superseded AI summary implementation, unused quota refund routine and obsolete configuration write; remove tests solely for deleted code, retain active feature tests.
- Patch the development-only `fast-uri` dependency. Expand CI to run Windows tests and build, Firestore emulator tests and high-severity runtime dependency audits.
